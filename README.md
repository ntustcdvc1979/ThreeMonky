# 三隻猴子 🙊🙉🙈

三人一組的傳話遊戲。話從第一個人傳到第三個人，還會剩下多少？

- 🙊 **比劃猴** — 拿手機看題目。只能比手畫腳，發出任何一個字就算犯規。
- 🙉 **傳話猴** — 看不到題目，只看得到比劃猴的動作。用嘴巴講給猜題猴聽。
- 🙈 **猜題猴** — 全程閉眼。只能用聽的，然後把聽到的東西**畫在紙上**。

站哪裡不重要，只要傳話猴看不到題目、猜題猴閉著眼就行。

純靜態網頁，**沒有後端、沒有資料庫**。`git push` 就是部署。

## 兩個畫面

| 網址 | 誰用 | 做什麼 |
|---|---|---|
| `https://ntustcdvc1979.github.io/ThreeMonky/` | 主持人的筆電，接投影機 | 規則、傳話方式、大倒數、時間到 |
| `.../ThreeMonky/play.html` | **每組的比劃猴各一支手機** | 出題、揭曉答案 |

**兩個畫面完全不通訊。** 題庫打包在網頁裡，各組自己抽題、自己揭曉。所以：

- 投影幕上**不會出現任何正式題目，也不會顯示主題**（只有範例題「太陽」），台下偷看也沒用。
- 答案是在**比劃猴自己的手機上**炸出來給那一組看。
- **沒有分數排行榜**。手機會顯示自己這組答對幾題，如此而已。

## 題庫與輪次

**一輪 = 一個主題 = 一題。** 全場主題一樣，同一主題裡各組拿到不同的那一題。四個主題就是四輪：

主題是**內部的分組方式，畫面上不會顯示**（投影幕和手機都只給題目本身）。它決定的是哪一輪出哪一批題、以及各組怎麼錯開。

| 輪 | 主題 | 題目 |
|---|---|---|
| 1 | 佛堂 | 八卦爐、佛杯、佛燈、拜墊 |
| 2 | 佛歸禮節 | 打毛巾、叩首、獻供、獻香 |
| 3 | 仙佛 | 濟公活佛、彌勒祖師、關聖帝君、南海古佛 |
| 4 | 十組 | 活動組、炊事組、文書組、大事記組 |
| 加碼 | 訓文 | 聖賢橋、功德銀行 |

**每一輪預設 4 分鐘**，投影端可以用 <kbd>+</kbd> <kbd>-</kbd> 或 <kbd>1</kbd><kbd>2</kbd><kbd>3</kbd> 現場調。

**最後的「訓文」是加碼題，只有自願的組別上**，不是全場一起玩。所以它只有兩題，也可以比前面難。打完第 4 輪之後，手機上會同時出現「我們到這裡就好」和「挑戰加碼題」兩顆按鈕 —— 不想上的組直接收掉看總結，自願的組才往下走。

題庫裡標了 `volunteer: true` 的主題就是加碼題，一定要放在最後面。

分派方式是 `slot = ((組號 - 1) + (輪次 - 1)) % 4`，保證三件事：

1. **相鄰組號永遠不同題** — 隔壁桌絕對不會跟你比一樣的
2. **會共用同一題的組固定差 4**（1&5、2&6、3&7、4&8），永遠不是隔壁
3. **同一組四輪拿到四題不同的** — 不會四輪都落在同一個位置

每個主題的四題還會先用當天日期洗過，所以同一個組號在不同場次拿到的不是同一題。

> **4 組以內完全不撞題。** 5–8 組的話，每主題 4 題分給 8 組，鴿籠原理擺在那裡，一定會有一對共用同一題 —— 能做的只是讓他們離得夠遠（就是上面第 2 點）。超過 8 組就要考慮加主題了。

## 現場怎麼跑

### 活動前

1. 手機開一次 `play.html`，確認載得進來（第一次載完就會存進離線快取）。
2. 筆電接投影機，開投影端，按 <kbd>F</kbd> 全螢幕。
3. 場地偏暗的話按 <kbd>C</kbd> 切暗場。

### 當天

1. **封面** — 標題頁，沒有 QR。
2. **規則 / 話怎麼傳** — 三隻猴子各自的限制。
3. **範例題** — 找一組上台用「太陽」示範一次。
4. **交接** — 每組派一個人當比劃猴，**在這一頁掃 QR Code**（掃不到就直接念旁邊那行網址），選一個代表數字，然後等你喊開始。
5. **正式輪** — 投影幕打出「第 N / 4 輪」和大鐘，按 <kbd>S</kbd> 跑 3・2・1，倒數自動開始。各組比自己手機上的那一題。
6. **時間到** — 按 <kbd>→</kbd> 翻到 hype 畫面，猜題猴睜眼、大家看畫。比劃猴在手機上按「答對了 / 沒猜到」，答案就會在他們自己的手機上揭曉。
7. 重複 5–6，共四輪。第五輪是**加碼題**，投影幕會打出「徵求自願組別」，只有自願的組別上。還要更多按 <kbd>Esc</kbd> → 「➕ 再加一輪」（主題會從第一個繞回來）。

> **選對組號很重要。** 組號直接決定你拿到哪一題，選錯就會跟別組比到一樣的。

## 投影端鍵盤

| 鍵 | 動作 |
|---|---|
| <kbd>→</kbd> <kbd>空白</kbd> <kbd>Enter</kbd> | 下一頁 |
| <kbd>←</kbd> | 上一頁 |
| <kbd>Esc</kbd> | 跳關選單（也能從這裡再加一輪） |
| <kbd>F</kbd> | 全螢幕 |
| <kbd>S</kbd> | 3・2・1 開始，跑完自動接上倒數 |
| <kbd>T</kbd> | 倒數 開始 / 暫停 |
| <kbd>R</kbd> | 倒數重設回本輪預設秒數 |
| <kbd>+</kbd> <kbd>-</kbd> | 加 / 減 30 秒 |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | 本輪設成 3 / 4 / 5 分鐘並重新開始 |
| <kbd>C</kbd> | 亮場 / 暗場 |
| <kbd>H</kbd> | 收起 / 打開角落的小 QR |
| <kbd>M</kbd> | 靜音／取消靜音（背景音樂和嗶聲一起） |

加時對各組是**自動生效**的——手機端根本不計時，全場只看投影幕這一個鐘。

## 背景音樂

投影端會放一段輕快的循環當底。**第一次按任何鍵（或點控制列）才會開始響** —— 瀏覽器不准網頁在使用者互動之前自己出聲。按 <kbd>M</kbd> 或控制列的「🎵 音樂」可以隨時關掉。

這段音樂是 [`assets/bgm.js`](assets/bgm.js) 用 Web Audio **即時合成**的，不是音檔：repo 裡一個二進位檔都沒有，也沒有授權問題。代價是它就是一段會一直繞的簡單和弦進行，不是真正的配樂。

**想換成真的音樂**：把音檔放進 `assets/`，再把 [`assets/bgm.js`](assets/bgm.js) 最上面的 `var FILE = null;` 改成它的路徑（例如 `"assets/bgm.mp3"`），合成的那套就會自動退場。記得也把檔名加進 [`sw.js`](sw.js) 的快取清單，離線才播得出來。

## 改題目

題目全部在 [`assets/terms.js`](assets/terms.js)，那支檔案裡沒有任何邏輯，放心改。

```js
{
  id: "shrine", name: "佛堂",
  terms: [
    { id: "a1", t: "八卦爐", hint: "三隻腳的爐、八卦紋、插著香" },
    ...
  ]
}
```

- `id` — 不能跟別題重複。之後插新題不要改舊的 id。
- `hint` — 選填，只在揭曉畫面顯示「畫重點：⋯」。
- **一個主題請維持 4 題**。塞第 5 題不會壞，但「各組不同題」的分派會跟著變鬆；要多題不如多開一個主題。
- **主題數 = 輪數**。加一個主題就多一輪，投影端會自動跟著長出來，不用改程式。
- **挑題原則**：最後一關是閉著眼睛聽描述、把它畫出來，所以只收**畫得出輪廓的具象詞**。
- 主題名字只出現在這支檔案裡，畫面上看不到，所以取名不用管長度或好不好唸。

改完直接 `git push`，GitHub Actions 會自動部署。頁面用 stale-while-revalidate 快取，所以**手機重整一次會拿到新版**（第一次重整還是舊的、第二次才是新的，這是快取策略的正常行為）。要強制清掉所有舊檔，把 [`sw.js`](sw.js) 最上面的 `CACHE = "tm-v6"` 版號 +1。

## 部署

**第一次要手動開一次 Pages**：去 **Settings → Pages → Source** 選 **GitHub Actions**，然後回 Actions 頁把失敗的那次 re-run。之後每次 push 到 `main` 就會自動上線，不用再碰設定。

（workflow 沒有用 `configure-pages` 的 `enablement: true` 自動開，因為那需要 token 有 repo administration 權限，預設的 `GITHUB_TOKEN` 沒有。）

所有資源都用相對路徑，所以 repo 叫什麼名字都能跑。QR 編的網址是從投影端當下的網址推出來的，沒有寫死任何 domain。

同一天辦兩場、不想兩場撞題的話，投影端網址加上 `?s=A7K3`（隨便一組字母數字），QR 會自動把它帶給手機。不加的話當天所有手機會用日期算出同一個順序。

## 常見狀況

| 狀況 | 怎麼辦 |
|---|---|
| 比劃猴不小心重整手機 | 會跳出「要接著玩嗎」，按了就回到同一輪、同一題 |
| 手機螢幕自己暗掉 | 按「開始比」時會自動要求保持喚醒；不支援的瀏覽器會出現提示，請他把自動鎖定調長一點 |
| 某組手機沒電 | 換一支手機、重選同一個組號，會拿到同一題 |
| 現場沒網路 | 只要之前開過一次就能離線玩（Service Worker 需要 https，GitHub Pages 本來就是） |
| QR 掃不到 | 直接念投影幕下方那行網址 |
| 想讓某組多一點時間 | 投影端按 <kbd>+</kbd>，全場一起加 |

## 本機測試

Service Worker 和螢幕喚醒都需要 https 或 localhost，`file://` 開會少這兩個功能。起一個本機伺服器再測：

```bash
npx serve .
```
